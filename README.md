## 开发环境

- JDK 27
- JavaFX 27
- Maven 3.9+

项目使用标准 JVM + JavaFX 运行，不再使用 GraalVM / GluonFX Native Image 打包。

## 运行

```bash
mvn javafx:run
```

## 构建

```bash
mvn clean verify
```

本项目是开源的，不会写入和创建额外业务数据。
