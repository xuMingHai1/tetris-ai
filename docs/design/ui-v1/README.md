## 交付与使用

- [动态预览 preview.html](preview.html)：下载或克隆仓库后，用现代浏览器直接打开。无需构建、服务端、联网或密钥。GitHub 文件页只显示源码。
- 本文：设计取舍、尺寸、颜色、交互、源码差异与验收要求。
- [AI 架构说明](../../architecture/ai-engine.md)：游戏与 AI 的职责边界。

预览可播放、暂停、继续、重播一段示例落子，切换模式只改变界面展示。它不是游戏实现，不绑定游戏快捷键，也不发起 Jev 请求。分数、动作序号、三块预览、决策过程均为示例。开发不得移植 HTML 中的示例棋盘、碰撞计算或计分作为生产规则。

## 已确认的方向

采用浅灰背景、靛蓝强调色，以及左侧对局信息／中央棋盘／右侧 AI 驾驶舱的三栏布局。棋盘和周围面板保持同一明度体系；方块使用低饱和色。通过动作执行高亮、硬降短拖影、消行和分数更新体现科技感。

此前的强霓虹、鲜艳青紫撞色、深色独立棋盘和工业风不作为本次实现方向。后续优化优先调整留白、文字层级、材质和节奏，不重新更换主题。

视觉细节以预览为准，行为与能力边界以最新源码为准；本文记录两者差异。发生冲突时明确记录，不用示例覆盖生产事实。

## 布局与组件

尺寸为逻辑像素参考，JavaFX 按字体度量与显示缩放调整。桌面优先参考 1024px 宽的预览内容区。

| 区域 | 基准 | 内容与约束 |
| --- | --- | --- |
| 顶栏 | 水平内边距 28，垂直 19 | TETRIS / AI 品牌；预览标识仅用于设计稿 |
| 模式栏 | 标题 23px，模式按钮 12px | 自由对局、模式说明、控制方式；不可凭显示选中状态假装已切换 agent |
| 主体 | 列宽 142 / 自适应 / 260；间距 24；内边距 20 / 28 / 28 | 棋盘为视觉中心，左右顶部对齐棋盘框 |
| 对局信息 | 得分 38px，消行／等级 23px | 分数使用等宽数字；下一块区域与当前控制分组 |
| 棋盘框 | 最大宽 280；内边距 10；圆角 13 | 示例 10×20，棋盘宽高比 1:2；生产读取实际行列；格间隔 1 |
| 方块 | 圆角 2，极轻上沿高光 | 实块、落点空心轮廓、创意目标图层要能区分 |
| 驾驶舱 | 圆角 13，内部留白约 19 | agent、真实状态、目标、动作序列、接管入口 |
| 控件 | 普通圆角 8，主要按钮高 42 | 触屏至少 44；键盘焦点清晰；禁用状态有区别 |
| 辅助文字 | 11–12px | 主要信息不能只依赖颜色；中文优先，技术标签简短 |

字体优先使用系统可用的 Segoe UI / Microsoft YaHei / sans-serif；无需为还原设计引入在线字体。正文 14px，面板标题 15px，避免过多粗体。

预览在 800px 以下收紧列间距；680px 以下将驾驶舱移到下方。当前 JavaFX 窗口不可调整大小，响应式窗口属于后续实现决策：先保证桌面布局完整，再评估开启缩放，不能只删除 `setResizable(false)`。桌面验收应覆盖 100%、125%、150% 显示缩放。

## 交互与状态

| 状态 | 展示要求 | 行为约束 |
| --- | --- | --- |
| 手动 | 显示手动控制；AI 信息保持明确的非执行状态 | 手动输入优先；接管取消待返回请求 |
| 就绪 | 展示实际配置的 agent 和目标 | 未配置 Jev 时不得显示已连接 |
| 决策中 | 点状轻提示、简短“选择落点” | 由真实请求生命周期驱动，不伪造耗时、置信度或模型解释 |
| 执行中 | 当前动作强调，已完成动作打勾 | 按真实执行记录展示；失败或被取消的剩余动作不能显示完成 |
| 暂停 | 棋盘柔和遮罩，按钮改“继续” | 生产暂停取消 pending decision；继续不能恢复已经失效的远程结果 |
| 回退／异常 | 明确“已切换本地策略”或失败原因 | 不把 fallback 显示为 Jev 成功；必要时显示不可用原因 |
| 消行／本步完成 | 消行动效、真实分数更新 | 完成以模型事件为准，不以动画结束推导 |
| 游戏结束 | 棋盘遮罩和明确结束状态 | 停止执行提示并清理过期视觉；重新开始沿用实际游戏生命周期 |

预览中的“播放动效／重播动效”只服务设计审阅，不属于生产按钮需求。生产主操作文案根据真实生命周期确定。创意目标面板默认折叠；展示目标图案、真实进度与生存回退信息，具体数据绑定在接入阶段实现。

## 动效基准

| 动作 | 预览时长 | 实现要求 |
| --- | --- | --- |
| 决策提示 | 单次 560ms | 预览固定节奏；生产随真实状态结束，不人为等待 |
| 横移 | 示例三格共 310ms | 平滑减速；实际路径由执行事实提供 |
| 硬降 / 拖影 | 190ms / 240ms | 短而干净，落点与网格精确对齐 |
| 落地反馈 | 110ms | 极轻压缩回弹，不改变逻辑坐标 |
| 消行 | 扫光 350ms；格子 260ms，逐格间隔 12ms | 最长约 368ms，无全屏闪白 |
| 剩余格下移 | 240ms | 依据真实消行前后快照插值，不另算消行 |
| 分数浮层 / 数值反馈 | 540ms / 220ms | 示例 +100 不能成为生产计分常量 |

这些是视觉参考，不是游戏时间规则。当前 `GameWorld.applyAiPlan` 同步按序执行；若需要逐动作动画，应增加轻量只读执行事件或展示快照，不能为了播放这段动效而 sleep、延迟重力或修改远程 deadline。状态已经前进时，应取消过期插值并对齐最新事实。新局、接管、暂停和关闭窗口时清理动画及监听器。支持关闭或减少动效，结果仍须完整呈现。

## 与当前源码的差异及接入位置

以下对应核对基线，不承诺未来源码接口保持不变。

| 设计项目 | 当前事实 | 开发交接要求 |
| --- | --- | --- |
| 三栏布局 | `view/GameView` 使用中心棋盘与右侧信息栏 | 在展示层重新编排；保留现有时长、等级控制、语言切换和版本入口，可收入紧凑辅助区 |
| 棋盘／方块绘制 | `GameContextView` / `AbstractBlockView` 观察并绘制游戏格子 | 统一背景、方块材质和覆盖层；不复制碰撞规则 |
| 得分、消行、等级 | `GameWorld` 已暴露只读 Property | 直接绑定生产值，示例数字不进入运行资源 |
| 下一块 | `nextTetrisProperty` / `NextBlockView` 当前只有一块 | V1 落地先显示一块；三块队列需独立扩展真实只读预览，不能额外调用 generator 推进随机序列 |
| 手动 / Heuristic / Jev 切换 | `AiPlanningAgentFactory` 在启动时按环境创建 agent；F2 只切换 AI 开关 | 初版显示“手动 / 已配置 AI”；如实现三项即时切换，先补生命周期与配置能力；不能自动开启远程请求 |
| AI 状态／动作清单 | 已有 `AiPlan`；没有与预览一一对应的 UI 状态接口 | 从真实 executor / runtime 暴露最小必要只读信息；不要将网络请求或 AI 搜索放进 View |
| 心形目标 | #36 已加入 `BUILD_SHAPE`、`ShapeTarget.HEART`；仅 `action` agent 支持非 survival 目标 | 不能在 Jev 模式提供可执行的 build-shape 选择；能力不匹配时禁用并说明原因 |
| 心形图案与颜色 | HEART 为底部居中的 6×8 occupancy mask；尚无 settled-color AI 状态 | 本预览已对齐 6×8 图案；只读生产 target，颜色目标、自定义图案仍待单独设计 |
| 快捷键 | A/D 移动、S 下落、←/→ 双向旋转、Space 开始/暂停、F2 切换 AI | 预览中的方向键移动、↑旋转、Space 硬降只是建议，不能直接替换。首轮保留既有键位并更新显示；重映射需单独确认 |
| 暂停 | `startOrPauseGame` 会取消 pending AI | 演示暂停动画不等于生产请求可恢复；继续需遵循有效 snapshot / generation 规则 |

入口参考：`src/main/java/xyz/xuminghai/tetris/TetrisApplication.java`、`view/`、`game/GameWorld.java`、`ai/AiPlanningAgentFactory.java`、`ai/ShapeTarget.java`，样式与文案位于 `src/main/resources/css/`、`src/main/resources/i18n/`。

## 建议实施顺序与验收

1. 先完成浅灰靛蓝主题与三栏静态布局，绑定既有分数、消行、等级和单块预览。
2. 接入实际控制状态、暂停／接管与 AI 最小只读展示，覆盖不可用、取消和 fallback。
3. 加入视觉插值、消行和分数反馈，验证不改变规则、seed 序列、AI deadline 或执行结果。
4. 最后接入创意目标展示；三块预览、运行时换 agent、快捷键调整作为明确的能力扩展分别评估。

- [ ] 棋盘与外围明度统一，配色、层级、留白与预览一致。
- [ ] 桌面显示缩放下无裁切、遮挡、模糊文字；棋盘格保持方形。
- [ ] 实块、预计落点、目标图层与暂停遮罩能够清楚区分。
- [ ] 未配置远程能力时显示准确；不硬编码“JEV / REMOTE”。
- [ ] 待返回请求遇到手动输入、暂停、新局、关闭时不会回写过期状态。
- [ ] 动作进度、消行、分数来自真实游戏事件，关闭动效不影响结果。
- [ ] 现有键位、等级调节、语言切换、时长与版本功能仍可访问。
- [ ] 新增生命周期行为有针对性测试；按 `AGENTS.md` 跑适用验证并观察 PR CI。
